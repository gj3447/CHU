# CHU와 CHU_OS — 개념과 컴퓨터 기반 구현의 구분

2026-10-13 갱신 · 이 설명은 SECONDARY_AI. 최신 근거는 별도 보존한
[계산가능성 범위 원문](sources/USER_PRIMARY_CHU_COMPUTABLE_SCOPE_2026-10-12.txt)(USER_PRIMARY)이다.
[포괄 사례 원문](sources/USER_PRIMARY_CHU_UNIVERSAL_SCOPE_2026-10-12.txt)도 함께 보존한다.
[앞선 명명 원문](sources/USER_PRIMARY_CHU_CHU_OS_2026-10-12.txt)의 `같음`, `내생각에는`도
그대로 보존한다. 후속 명확화를 적용하되 과거 발화를 다시 쓰지 않는다.

**CHU = Computable Hyper Universe**는 컴퓨터·인간의 뇌·우주를 포괄하는 철학적 개념이다.
모든 것이 하이퍼그래프로 이루어져 있다는 사용자 관점에서 **계산가능한 것은 모두 CHU**다.
이 포괄 기준과 계산가능성의 구체적 형식 명세는 구별한다. 이번 원문에 없는 유한성,
튜링 완전성, 모든 질의의 결정가능성 등을 추가 입장 조건으로 두지 않는다.
앞선 AI 설명의 “인지능력체 자체”를 CHU 전체의 제한적 정의로 사용한 것은 범위를 좁힌 해석이다.
인지는 CHU 안에서 다룰 수 있는 성질과 연구 주제이며, 모든 CHU 사례의 입장 조건으로 두지 않는다.
CHU_OS는 이 철학을 컴퓨터에서 구체화하는 **특정 운영체제 구현 프로젝트**다.
컴퓨터를 CHU의 사례로 보는 것과 그 컴퓨터에서 CHU_OS를 실행하는 것은 별개의 관계다.

| 이름 | 현재 작업상의 의미 | 연결의 의미 |
|---|---|---|
| CHU | 계산가능한 모든 것을 포함하는 Computable Hyper Universe | 사용자의 하이퍼그래프 관점; 인지능력은 필수조건이 아님 |
| CHU_OS | 특정 컴퓨터 기반 운영체제 구현 프로젝트 | CHU 철학을 구체화하는 한 구현 경로 |
| HSWM | 지속적 의미·인지 그래프와 국소 연산·전이 방식 | CHU_OS의 인지 동작을 구성하는 기존 연구·구현 경로 |
| OMC | 의미·연결성을 보존하는 하드웨어 적응 배치 | 컴퓨터 구현에서 데이터·프로그램·작업 배치를 담당 |
| HOH | 사람·기기의 대화·상호작용 접점 | 입력·결과·평가를 위 구조와 연결 |

사용자는 컴퓨터가 CHU가 될 수 있고, 인간의 뇌와 우주도 CHU라고 명확히 했다.
이는 개념의 범위를 정하는 사용자 철학이다. 세 대상을 같은 물리적 객체로 병합하거나
동일한 계산 구조·인지능력·의식을 가진다고 확장하지 않는다. 원래의 “우리 우주 자체도
월드모델 CHU”라는 관점도 그 발화 문맥과 함께 보존한다.

개념·사례·모형·구현을 구별한다. CHU는 공통 관점이고, 컴퓨터·뇌·우주는 그 관점에서
다루는 대상이며, 그래프와 상태 전이는 이를 설명하는 모형이다. CHU_OS의 자료구조·커널은
그 모형의 일부를 실행하는 구현이다. 특정 그래프 DB나 OS의 제약으로 철학 전체를 정의하지 않는다.
관계·변화·계산·세계의 구체적 작업 정의는 [철학 v1.1](../philosophy/README.md)의 AI 제안으로
구분한다. 사용자 원문만으로 모든 대상의 계산가능성이나 하나의 유일한 형식 체계가 증명되지는 않는다.

[개념 그래프](../philosophy/graph/README.md)의 `./chu concept query scope`는
계산가능한 것의 포괄(C15), 인지 비필수(C16), 모든 것을 하이퍼그래프로 보는 관점(C17)을
각각 원문·판본과 함께 반환한다. C15/C16의 `SOURCE_SUPPORTED`는 사용자 정의의 출처가
있다는 뜻이며, C17을 경험적 사실로 검증했다는 뜻이 아니다.

[2026-09-27 원문](sources/USER_PRIMARY_CHU_HSWM_SCOPE_2026-09-27.txt)은 이미 CHU의
범위에 월드모델과 HSWM을 포함했다. [2026-09-29 OS 원문](sources/USER_PRIMARY_CHU_HYPERGRAPH_OS_2026-09-29.txt)은
당시 구현 목표로 보존한다. 과거 사용자 문장을 새 용어로 치환하지 않고, 현재 설명에서
개념 CHU와 구현 CHU_OS를 구별한다. Lean의 `axiom CHU : Type`도 해당 형식 체계의
기호이며 이 명명 정정만으로 변경하지 않는다.

후속 [사용자 지시](sources/USER_PRIMARY_CHU_PHILOSOPHY_FIRST_2026-10-12.txt)는 철학을 먼저
정리하고 CHU_OS를 별도 저장소로 두는 방향을 확정했다. 철학 v1.1은 v1의 인지 중심 설명을
이번 포괄 범위에 맞게 정정한 판본이며, 구체적 정의 제안 전부가 사용자 승인된 공리라는 뜻은 아니다.
CHU가 개념·이론의 정본을 맡고 CHU_OS가 구현을 맡는다. 기존 checkout에는 호환을 위한
OS 파일이 남을 수 있다. 실제 이관·검증·소비자 전환 상태는
[분리 기록](../docs/CHU_CHU_OS_REPOSITORY_SPLIT.md)을 따른다.

공유 KG에서 조회한 `sym:Concept:computable_hyper_universe_(chu)`는 출처 없는 과거
database 설명과 `UNSPECIFIED / UNKNOWN` 상태를 반환했다. `sym:Directory:chu`는
디렉터리 기록이다. 둘을 이번 정의의 승인 근거로 삼거나 새 CHU_OS 개체와 자동 병합하지 않는다.
이번 사용자 원문은 소유 저장소에서 보존하며 공유 KG 발행은 수행하지 않았다.
