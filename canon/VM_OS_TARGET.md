# CHU의 실행 대상 — VM에서 부팅하는 OS

2026-09-30 사용자 원문: [원본 발언](sources/USER_PRIMARY_VM_OS_HSWM_2026-09-30.txt).

사용자가 명시한 목표는 **가상머신 위에 올라가는 OS이며 HSWM을 실행할 수 있어야 한다**는 것이다.
기존 AI 연구 D04의 “사용자 공간 작업환경/오버레이로 시작”은 이 목표를 충분히 표현하지 못했다.
현재 아키텍처와 계획에서는 그 가정을 대체한다. 과거 연구와 실제 측정 결과는 이력으로 보존한다.

다음은 `SECONDARY_AI` 구현 선택이며 사용자 발언 자체가 아니다:

- 첫 부팅 실험은 Linux 커널, Ubuntu 최소 rootfs, systemd를 재사용한다.
- Linux 드라이버·프로세스·메모리·VFS 위에 CHU 그래프 시스템 서비스를 구현하고
  HSWM 실행기와 연결하는 방향을 제안한다. 이것이 완성된 CHU OS라는 주장은 아니다.
- 자체 커널 구현 여부는 미확정이다. 현재 실험의 Linux 재사용을 최종 커널 결정으로 취급하지 않는다.
- 표준 RDF/SHACL/PROV 도구는 데이터 교환·검증·근거 역할이다. OS 기능을 대신하지 않는다.

실행 계약과 남은 검증: [VM OS 설계](../os/README.md), [정본 작업 그래프](../plan/chu_os_plan.graph.json).
