# A4 — 존재론적 선례 (Tegmark CUH/MUH, univalence 채택 함의)

**축 질문**: "우주 = 계산가능 하이퍼우주" 주장의 외부 선례가 있는가.
**축 합성**: Tegmark CUH가 computable 제약의 명확한 선례(S1, GROUNDED). CUH 비판(unfalsifiability/measure problem/Gödel)도 잘 확립되어 CHU가 상속(S2, GROUNDED). univalence→구조실재론 형식선례 실재하나 자기제한적(S3, PARTIAL). 결정적: CUH plenitude(∃-many) vs Ruliad unique-totality(관찰자 slice)는 상호배타적 존재양화 → CHU가 둘 다 못 빌림(S4, DIVERGES).

---

## A4S1 — primary-source — `GROUNDED` (HIGH)
Tegmark arXiv:0704.0646 §VII: "Computable Universe Hypothesis (CUH): The mathematical structure that is our external physical reality is defined by computable functions" — 구조 정의 관계가 유한스텝 halt 계산으로 구현가능. 제약 이유 명시 = Gödel 불완전성 + Church-Turing 비계산성("otherwise correspond to unsatisfactorily defined relations ... infinitely many computational steps"). CUH가 cosmological measure problem 완화 + 법칙 단순성 설명 주장.
- 출처: Tegmark "The Mathematical Universe" arXiv:0704.0646 §VII
- caveat: CUH = 개별 구조의 관계가 computable해야 한다는 selection 원리이지 "하이퍼우주 자체를 하나의 계산가능 객체로" 정의하진 않음 — CHU와 scope mismatch 가능성(PARTIAL 여지). Schmidhuber halting-program 가설과 명시 구분.

## A4S2 — academic-critique — `GROUNDED` (MEDIUM)
Tegmark MUH/CUH 3축 비판: (1) unfalsifiability(Woit "텅 빔/반증불가", Ellis "검증불가 무한앙상블"); (2) measure problem(모든 구조 동등존재면 왜 이 우주? → 임의 external measure 도입, 무선택 motivation 자기훼손); (3) Gödel(Hut/Alford, 수학구조가 자기 완전서술 가능한가). CUH 확장은 Schmidhuber speed prior와 경쟁(모든 계산가능 구조 동일 weight = 무한집합상 정의불가 비판). Piccinini physical computation 비판이 pancomputationalism 자체 기각. **CHU가 CUH 계승 시 이 비판 상속** + Schmidhuber 우선권/차별화 요구 + "계산이란 무엇인가" 논쟁.
- 출처: Wikipedia MUH; Woit "Not Even Wrong"; arXiv:1206.0376; Schmidhuber quant-ph/0011122; arXiv:0907.0216; Piccinini PhilPapers
- caveat: Piccinini-Tegmark 직접연결 문헌 미확인(일반 pancomputationalism 비판만). modal realism(Lewis) 비교 미커버. Gödel 비판 Wikipedia 경유.

## A4S3 — formal-bridge — `PARTIAL` (MEDIUM) [SINGLETON — VERIFY]
형식 선례 실재: Voevodsky univalence(동형=항등)가 철학계에서 ontic structural realism 형식근거로 채택(Ladyman & Presnell 2024 "Univalence and Ontic Structuralism", Found. Phys.). Ladyman & Presnell 2019 "Hole Argument in HoTT"는 diffeo-related spacetime을 univalence로 동일시 시도 — **단 논문 자체가 "univalence는 type에만, spacetime model은 type 아님"이라 naive 물리적용 제한**. Arsiwalla/Gorard homotopy types가 CHU 직접 선례(project_chu_wolfram_absorption과 정합).
- 출처: arXiv:2407.14238 (Ladyman&Presnell 2024); Found.Phys. 2019 Hole Argument; HoTT Book arXiv:1308.0729; arXiv:2105.10822
- caveat: univalence는 엄밀히 type 사이만 — CHU states/paths가 formal type인지 별도 증명 필요(WebSearch로 CHU 내부 형식화 미확인). "동형=동일" 존재론 정당화가 임의 물리대상 자동이전 안 됨.

## A4S4 — falsification — `DIVERGES` (HIGH) ★ 핵심 반증
CUH = multiverse/plenitude 존재론(Tegmark Level IV의 Gödel-complete computable 제한, 각각 별개 실재 우주 = modal realism, many structures). Ruliad = 정반대 cardinality: **ONE unique necessary single entangled-limit object**, 물리/다원성은 관찰자의 slice(별개 실재 아닌 관찰자상대적 현상). **CHU는 CUH를 존재론 선례로 빌리면서 Ruliad 동일성 주장 불가**: "존재=computability, ∃-many 별개실재 구조"(CUH)와 "존재=유일 ∀-포괄 entangled totality, 다원성=관찰자상대"(Ruliad)는 **상호배타적 존재양화 구조**. 제3자 비판(Natal 2024, arXiv:2411.12562)이 Wolfram·Tegmark가 *같은* modal/actual conflation 오류(수학적 potentiality를 물리적 actuality로) 범한다 논증 → CHU가 둘 다 무비판 접합 시 이 결함 이중 상속. univalence는 물리/경험 논증 없는 수학기초 공리선택 — CUH/Ruliad에서 "존재론 선례" 지위 상속은 math-foundations→physics-ontology category leap.
- 출처: Wolfram Ruliad; Wolfram 2026 "What Ultimately Is There? Metaphysics and the Ruliad"; Wikipedia MUH; arXiv:2411.12562 (Natal); Tegmark arXiv:0704.0646
- caveat: CHU 1차 정의(SYMPOSIUM-internal) 미독 — task 서술 CHU(Ruliad 동일+CUH 선례) 기준 평가. CHU가 strict identity를 이미 disclaim할 가능성 미확인.
